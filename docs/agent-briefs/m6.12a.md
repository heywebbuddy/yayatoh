## Scope (each fully tested)
- A **rule builder**: keep together (party, association, tag), keep apart, VIP nearest the stage, accessibility needs near exits, table capacity, hard vs soft rules with weights.
- A **tabu-search solver** in a **Web Worker** (P6-10) that produces an **editable proposal**; deterministic for a given seed; cancellable; progress reported.
- **Accept per table or all**; the proposal never touches **manual placements** (locked seats are fixed inputs).
- An accessible alternative to drag (list-based seat assignment and a text summary of the proposal); 24 px minimum targets.

## Acceptance
- **400 guests seated in ≤ 5 s** in CI's headless browser with **no hard-rule violations**; soft-rule score reported.
- **Manual placements are never overwritten** (property test over random locks).
- Accepting a proposal goes through commands (audited, idempotent); isolation.
- E2E: build rules, run, review, accept one table then all; keyboard only, axe both themes, RTL.
