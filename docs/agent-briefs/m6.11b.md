## Scope (each fully tested)
- **Seat channels and allotments**: assign seats or blocks to channels (public, box office, sponsors, promoters with a code), with release times. A seat in one channel can't be sold through another.
- **Layout revisions**: every save is a revision, with a diff view (seats added, removed, renumbered) and rollback. Rollback keeps sold seats (it refuses or remaps them, explained).
- **Underlay tracing**: upload a venue image (PNG/PDF page), scale and position it under the editor, at an opacity.
- **Venue layout library**: save a layout to the org's library and start a new event from it.
- An accessible alternative for every canvas action (a list view with keyboard editing).
