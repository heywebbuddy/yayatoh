## Scope (each fully tested)
- **`GET /v1/me/tickets`:** upcoming and past, with keyset paging, from the same source as the web's My tickets.
- **`GET /v1/me/tickets/{id}`:**
  - the QR code string, short code, `rev` and status
  - ticket type, seat label, and entrance or checkpoint names
  - an event summary (times as instants plus the event time zone) and the venue
  - the organizer's public branding for theming
  - what the holder may do: transfer, with its cutoff and fee
- **Orders:** `GET /v1/me/orders` and `GET /v1/me/orders/{id}` (lines, totals in minor units, refund policy, refund-request status).
- **Refunds:** `POST /v1/me/orders/{id}/refund-requests` over `requestRefundCommand`.
- **Transfers:** `POST /v1/me/tickets/{id}/transfers` and `DELETE /v1/me/tickets/{id}/transfers/{transferId}` over the holder transfer commands, honouring `transfersAllowed` and `transferCutoffHours`. If the type charges a transfer fee, return a web link to pay it instead.
- **Claims:** `GET /v1/claims/{token}` and `POST /v1/claims/{token}` for a signed-in person.
- **Wallet:** `GET /v1/me/tickets/{id}/wallet?platform=apple|google` returns a pass URL through `WalletPassProvider` (the fake until the owner's accounts exist). Transfers void old passes through `walletPassSync`.
- **Responses and writes:** allowlist serializers, ETags, and idempotency keys on every write. Add canary and leak-crawler coverage for every new response; private columns never appear.
- Regenerate OpenAPI and the SDK.

## Acceptance
- For every seeded persona, `/v1/me/tickets` returns exactly the tickets the web's My tickets shows (contract test).
- A person never reads a ticket or order that isn't bought by or held by their verified email, and an unverified account gets 403 (isolation tests across both fixture orgs).
- After a transfer, the sender's list drops the ticket, `offlineVerdict` refuses the old code as superseded, and the old wallet pass is voided.
- Transfer cutoffs and refund policies are enforced by the commands, not just the routes.
- oasdiff shows only additions.
