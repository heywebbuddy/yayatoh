**Base:** the build branch, plus the newest merge branch that exists (`git merge origin/merge/next-3h`, else 3g). Phase 6 is built **behind flags** and an entitlement key (P6-13): anything that charges money or talks to a real third party goes through a port with a **fake in dev and CI**. No real vendor accounts, keys or network calls; `.env.example` names only.

## Scope (each fully tested)
- An **`IntegrationAuth` port** (P6-4) for OAuth connect, token refresh and revoke, with a **Nango adapter** and a **fake** used in dev and CI. Tokens live only behind the port (Nango holds them); we store connection ids and metadata, never tokens.
- The **connections page**: connect, status, last sync, pause, disconnect, per connector; entitlement `integrations` per connector.
- **Field mapping**: one UI for every connector (source field → Yayatoh field, transforms from a small allowlisted set, defaults), stored per connection and versioned.
- The **sync engine** on pg-boss: pull and push, cursors per object type, retries with backoff, **loop guards** (origin tagging so our own writes don't echo back), idempotency keys per external record, a per-connection concurrency of one.
- An **integration errors inbox**: grouped errors with the record, the step, retry and dismiss; nothing in it carries tokens.
- A connector SDK inside the module (`defineConnector`) that M6.4b–d plug into; a **demo connector** against the fake proves it end to end.

## Acceptance
- A sync **replayed twice writes once**.
- A **revoked connection stops within one run** and is shown as revoked.
- **Tokens never appear in logs**, errors, the inbox, audit rows or serializers (a canary token planted in the fake must not appear anywhere; add it to the leak canary).
- Isolation: a connection, mapping or error from one org is invisible to another.
- E2E: connect the demo connector (fake OAuth), map fields, run a sync, see an error and retry it, disconnect; keyboard only, axe both themes, RTL.
