## Scope (each fully tested)
- **Grouped, collapsible sidebar** for the org console: Events · Audience & marketing · Money · Site & content · Settings (section open state remembered per user). Every existing org page lands in exactly one group; profile-driven event sections unchanged.
- A global **Create** menu in the top bar: event, series, template, venue, coupon, page/blog post (each respecting permissions and entitlements).

- **Consistent page anatomy**: breadcrumb → title + primary action → summary → content, via the existing PageHeader everywhere in the org console.
