**Base:** the build branch, plus the latest merge branch (`git merge origin/merge/next-3g`, or 3f/3e, whichever is newest and exists). Phase 6 is built **behind flags**: anything that charges money or talks to a real third party goes through a port with a fake in CI.

## Scope (each fully tested)
- **Event catalog**: every public event with a versioned Zod schema, an example payload and a description. Thin payloads for PII (D21).
- **Org webhook endpoints** through the Svix port:
  - the customer portal (embedded, fake in CI)
  - retries, replay and a signing secret per endpoint
  - a test-send button
- **Public docs site**: a route in apps/web (e.g. /developers) generated from OpenAPI plus the event catalog, with guides (auth with API keys, pagination, idempotency, webhooks verification, sandbox). Every locale gets the shell; the API reference stays English.
- **SDK publish pipeline**: a CI job that builds `@yayatoh/sdk` for npm (dry-run only; the real publish needs the owner's npm token, logged in owner-inbox). Swift/Kotlin are generated as artifacts only.

## Acceptance
- Every public event has a documented, versioned schema (a test that the catalog covers every public outbox event).
- A payload never carries PII beyond D21's thin set (leak canary).
- Signature verification is documented and tested with the example code.
- Isolation.
- E2E: add an endpoint, test-send, see the delivery (fake); the docs pages render with a working search; keyboard only, axe, RTL.
