## Scope (each fully tested)
- **`GET /v1/public/events`:** search by text, date range, distance from a point, category and organizer, with keyset paging, over the public read model only.
- **`POST /v1/public/events/{slug}/checkout`** for a signed-in person (the `/v1/me` scope):
  - The same steps as `checkoutAction`: hold, payment, attach.
  - Returns `{orderId, paymentUrl, expiresAt}`. The return and cancel URLs are universal links on `app.yayatoh.com` that the app opens.
  - Requires an idempotency key, with the same promo-code rules and rate limits as the web.
- **Carts the app can't finish natively** (checkout questions, seat selection, approval, a transfer fee) get the web checkout URL instead, opened in the same browser session.
- **Virtual ticket types:** ticket types with virtual or livestream access are refused with `buy_on_web` and a web URL (P7-7).
