Read `common.md` (including its "Don't stall" section) and `mobile-common.md`. Then read `docs/plans/mobile.md` (row M7.1c and decisions P7-5, P7-9, P7-11), ADR 0025, and the code:

**Base:** `origin/main` after Wave 1 (M7.1b and M7.2a merged; see `mobile-common.md`).

## Scope (each fully tested)
- **API client:** the SDK with the base URL from config, a token callback, and `X-Yayatoh-Client` as `yayatoh-ios/<version> (<build>)`, `yayatoh-android/…`, `yayatoh-staff-ios/…` and `yayatoh-staff-android/…`. Add those four identifiers to `KNOWN_CLIENTS` (additive server change).
- **Session store:**
  - Access and refresh tokens in `expo-secure-store`.
  - One refresh at a time, so concurrent 401s wait for a single refresh.
  - A reused or revoked refresh token signs the app out and wipes the cache and local data.
  - Sign-in helpers for every M7.2a grant: email code, Apple through `expo-apple-authentication` with a nonce, Google through a maintained native library that returns an id_token (name it in your report), password, the two-factor step and step-up.
- **Server state:** TanStack Query with a persisted cache. Encrypt it with a random key held in secure storage (secure storage itself is too small for the cache). Clear it at sign-out.
- **Theme:** light and dark from the tokens, following the system with an in-app override. Tenant brand colours come from API responses at runtime; when the contrast is under 4.5:1, fall back to the default colours.
- **Translations:**
  - `use-intl` with catalogs in `packages/mobile-core/messages/` and each app's `messages/`, for all 13 locales.
  - The device locale, with an in-app override.
  - Right-to-left via `I18nManager`, reloading when the direction changes.
  - A parity test like the web's.
- **Deep links:** a router helper that maps universal links and push payloads to routes.
- **Version gate:** check `/v1/mobile/config` at launch (an update screen below the minimum, a soft nudge below `recommended`), and show the update screen on any 426.
- **Network state:** an offline banner helper, and Sentry initialised with scrubbing (disabled when no DSN is set).

## Acceptance
- Two simultaneous 401s cause exactly one refresh; a reused refresh token signs out and wipes local data.
- The persisted cache file can't be read without the key (the test reads the raw file).
- Every catalog has every key with valid ICU plurals per locale; an Arabic render is right-to-left (component test).
- A brand colour with poor contrast falls back to the default.
- A 426 or a below-minimum `/v1/mobile/config` shows the update screen with the right store link.
