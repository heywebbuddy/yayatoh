## Scope (each fully tested)
- An **Eventbrite connector** (on `defineConnector`): import events, ticket classes, orders and attendees into a chosen org through our commands (never direct inserts); money in integer minor units; times stored as timestamptz with the event's IANA zone; re-runnable with external-id idempotency; a dry-run preview with counts before writing.
- A **Google Sheets connector**: live two-way sync of an event's attendee list to a sheet (columns from the field mapping); our edits push, sheet edits pull on the next run; conflict rule documented (last-writer by row timestamp, with the losing value in the errors inbox).
- Both run against **recorded fakes** in CI (fixture Eventbrite account; fake Sheets API).

## Acceptance
- An import into a fresh org **reproduces the fixture account's counts** (events, ticket types, orders, attendees, revenue to the cent).
- Sheet edits **round-trip without duplicates**; deleting a row in the sheet never deletes an attendee (it flags it in the inbox).
- Imported orders are marked imported and never trigger payment or receipt emails.
- E2E: import wizard (connect, preview, import, result), Sheets link/unlink and a round trip; keyboard only, axe both themes, RTL.
