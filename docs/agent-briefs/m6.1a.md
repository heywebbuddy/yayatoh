## Scope (each fully tested)
- **Duplicate detection**: same email, same phone (E.164), fuzzy name + company (trigram), with a confidence score and the reason. It runs as a background job per org, and incrementally on new contacts.
- **Merge UI**: a duplicates queue, side-by-side compare, a field-by-field choice (default: most recent non-empty), and consent merged by the strictest rule (an opt-out wins).
  - Merge moves every reference across modules **exactly once**, through each module's public command or an outbox event `crm.contacts_merged.v1` that each owning module handles. Never write another module's tables.
  - **Undo** within 30 days restores the split exactly.
  - Audited, with step-up for bulk merges.
- **Person timeline**: a single chronological feed from projections only (no runtime joins): orders, refunds, check-ins, sessions attended, campaigns sent/opened/clicked, messages, donations, RSVPs, surveys. Filters by type and event. Keyset paging.
