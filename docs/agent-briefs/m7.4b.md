## Scope (each fully tested)
- **Camera:** `react-native-vision-camera` v5 scanning QR codes only, with the torch and a manual code entry; denied camera permission shows how to allow it.
- **Manifest:** download it for the enrolled event into `expo-sqlite` with SQLCipher (the key in the keychain), refresh it in the background, and delete it 24 h after the event ends and on wipe (`onWipe`).
- **Verdicts** from `checkin-engine` only (never re-implemented): admit, duplicate (with where and when), wrong checkpoint, superseded `rev`, refunded, unknown. Each shown with colour, text, a distinct sound and haptics, readable at arm's length.
- **Outbox:** every scan queued in SQLite and sent to `scans/batch` in batches of up to 500, with retry and backoff; the queue depth feeds M7.4a's heartbeat. A duplicate the server finds after sync is flagged on screen.
- **Speed:** the verdict in under 300 ms on a mid-range Android phone; measure in tests with the M7.1a benchmark and log the device-pass target.

## Acceptance
- Every M7.1a test vector gives the same verdict in the app as in Node (a test runs the vectors through the app's verification path).
- **Offline drill (X):** two phones offline admit the same ticket, reconnect, and the duplicate is flagged within 60 s (test with two simulated outboxes; Maestro flow for the device pass).
- The manifest file can't be read without the key; wipe and the 24 h expiry delete it.
- Component tests for every verdict and for denied camera permission; Arabic RTL. List the native dependencies added and their versions.
