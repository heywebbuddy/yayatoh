# U8 before/after screenshots

Build branch + batch 3i + U1 (before) and `agent/u8` (after), the seeded dev data, light and dark, 1280 and 390 px.
File names: `{before|after}-{screen}-{theme}-{width}.jpg`.

| Screen | What to look at |
|---|---|
| `create-event` | Before: a bare "Event type" dropdown. After: "What kind of event?", each option with a one-line description, and a summary of the chosen kind: its description and the sections it includes for this org. |
| `event-details` | Category: the org's own list (and "Manage categories" for owners and admins). Tags: a comma text box (before) vs a combobox with chips, suggestions and "Create …" (after). |
| `org-events` | The console list's category filter now lists the org's own categories. |
| `categories` (after only) | The new Settings → Event categories page: How it works, add a category (name + marketplace category), the ordered list with move up/down, rename, hide/show and event counts. |
| `categories-ar` (after only) | The same page in Arabic, right to left. |
| `organizer-page` | The organizer page of the seeded org (no tagged events, so no filter row: the filter appears only when listings have tags). |
| `organizer-tags` (after only) | An organizer page with tagged events (an e2e org): the tag chips filter ("All events", each tag with its count), the selected chip marked as the current page. |
