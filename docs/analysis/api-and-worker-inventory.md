# Yayatoh public API and background flow inventory

The API operations below come from the committed OpenAPI document. They are separate from the Next.js route-file counts. Event subscription literals and worker names are static detections and may omit dynamically assembled registrations.

## Public API operations

| Method | Path | Operation | Description |
|---|---|---|---|
| GET | /v1/health | getHealth | Liveness check |
| POST | /v1/auth/token | issueToken | Sign in (grantType password) or refresh (grantType refresh_token): a 15-minute access token and a rotating refresh token |
| POST | /v1/auth/revoke | revokeToken | Sign out a refresh token: its chain and every access token issued from it end |
| POST | /v1/auth/login | login | Sign in with email and password; returns a bearer session token (no cookies) |
| POST | /v1/auth/refresh | refreshSession | Keep a session alive: returns the token with its extended expiry |
| POST | /v1/auth/logout | logout | End the session; the token stops working at once |
| GET | /v1/me | getMe | The signed-in user |
